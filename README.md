# sync_tool

Shared clipboard (text, images, files) and "Send to" between your own Windows PCs —
direct, end-to-end encrypted. Copy a file with Ctrl+C on one PC, paste it with Ctrl+V on the other.

Install or update (PowerShell):

```powershell
irm https://raw.githubusercontent.com/lx50ak-source/sync-tool-releases/main/install.ps1 | iex
```

Uninstall:

```powershell
irm https://raw.githubusercontent.com/lx50ak-source/sync-tool-releases/main/uninstall.ps1 | iex
```

After installing on both PCs: right-click the tray icon on each → "اقتران جهاز جديد…" →
confirm the same 6-digit code on both.
